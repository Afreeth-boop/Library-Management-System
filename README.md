# Library Management System

A simple console-based Library Management System built using Java and Object-Oriented Programming (OOP) concepts.

## Features

- Display all available books and their details
- Borrow a book using its ID
- Return a borrowed book
- Check book availability
- Display member details
- Track the number of books borrowed by a member
- Menu-driven interface using a loop and switch statement

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- Git and GitHub

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/Afreeth-boop/Library-Management-System.git
   ```

2. Open the project in IntelliJ IDEA.

3. Make sure Java is installed and configured.

4. Open `src/Main.java`.

5. Run the `main()` method.

6. Follow the menu displayed in the console to manage books
